# ABAD ABOGADOS — sitio web estático

Versión actualizada siguiendo el wireframe minimalista de ABAD ABOGADOS.

## Estructura
- `index.html` — Home
- `nosotros.html` — Nosotros
- `servicios.html` — resumen de servicios
- `servicios/civil.html` — Derecho Civil
- `servicios/penal.html` — Derecho Penal
- `servicios/laboral.html` — Derecho Laboral
- `profesionales.html` — equipo
- `profesionales/*.html` — perfiles individuales
- `casos-de-exito.html` — listado de casos
- `casos/*.html` — fichas individuales preparadas para casos reales
- `contacto.html` — contacto y mapa

## Fotografías
La fotografía principal entregada por el cliente está en `img/foto-principal.jpg` y se usa en el Hero.

Las fotografías individuales de los abogados aún no se incorporan porque no fueron incluidas en el paquete.

## Casos de éxito
Las fichas están creadas, pero no contienen resultados ficticios. Deben completarse con casos reales y contenido autorizado por el estudio.
